# Blip — тестовые версии для Android

Соцсеть, которая начинается в двух метрах от тебя: телефоны находят друг друга по Bluetooth даже без интернета.

## Скачать последнюю версию

**[Скачать Blip.apk](https://github.com/Nagayzev05-commits/blip-releases/releases/latest/download/Blip.apk)**

1. Открой ссылку на Android-телефоне и дождись загрузки (около 22 МБ).
2. Открой скачанный файл и нажми «Установить». Если телефон спросит — разреши установку из браузера.
3. Если Google Play Защита предупредит — «Всё равно установить».
4. Открой Blip, заполни карточку и включи «Я на связи». Нужен включённый Bluetooth.

Это прототип для тестов. Все версии — во вкладке [Releases](https://github.com/Nagayzev05-commits/blip-releases/releases).
