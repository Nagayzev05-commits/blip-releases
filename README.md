# Blip — тестовые версии для Android

Соцсеть, которая начинается с тебя: телефоны находят друг друга по Bluetooth даже без интернета.

## Скачать последнюю версию

**[Скачать Blip.apk](https://github.com/Nagayzev05-commits/blip-releases/releases/latest/download/Blip.apk)**

Ссылка всегда ведёт на самую свежую версию — её можно сохранить в Telegram в «Избранное» и открывать с любого телефона.

1. Открой ссылку на Android-телефоне и дождись загрузки (около 23 МБ).
2. Открой скачанный файл и нажми «Установить». Если телефон спросит — разреши установку из браузера или Telegram.
3. Если Google Play Защита предупредит — «Всё равно установить».
4. Открой Blip, заполни карточку и включи «Я на связи». Если Bluetooth выключен, Blip сам предложит его включить.

Новая версия ставится поверх старой как обновление — карточка и переписка сохраняются.

Это прототип для тестов. Все версии — во вкладке [Releases](https://github.com/Nagayzev05-commits/blip-releases/releases).
